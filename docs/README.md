# 文档导航

1. [整体架构](architecture.md)：系统边界、模块职责和主数据流。

3. [受控代码验证执行](harness.md)：配置、快照、运行时选择和结果证据。

5. [内部模块边界](modules.md)：旧固定任务、服务和评测代码为何保留，以及它们不再承担的职责。
6. [开发与阅读指南](development.md)：本地启动、检查和源码阅读顺序。
