# 阶段六：架构说明与可复现交接

## 本轮范围

依据第34～36步；用户明确自行负责第35步，本轮不制作演示、不发起付费模型请求，不新增前端或Agent能力。

- 第34步：核对实现后写架构、职责、取舍、威胁模型、验收含义和限制，链接到实际代码与测试。
- 第36步的可代办部分：在独立源码副本、全新非editable环境锁定安装，运行无模型普通测试、一次脚本替身驱动的完整Agent链路、参考补丁CLI独立验收、格式检查和打包；检查候选发布材料。
- 第36步的个人部分：提供从请求到下一轮决策的阅读路径、自测题和空白练习，不把生成一份讲稿等同于用户已经能够独立讲解。

## 不扩大授权

不执行真实API调用、Git初始化/提交/发布、数据库schema清理、批量容器清理或许可证法律授权选择。复现复用本机uv缓存和固定Docker镜像，不描述成全新机器或冷缓存安装。默认不运行PostgreSQL集成，避免仅为文档变更重复积累schema。

## 文件职责

- `docs/architecture.md`：实现事实、设计取舍和边界；不用未实现的能力充数。
- `docs/reproduction.md`：PowerShell复现步骤、预期结果、故障排查与环境清洁范围。
- `docs/execution-walkthrough.md`：一次工具调用的追踪方法与个人自测；运行时替身证据和真实模型证据分开。
- `docs/release-readiness.md`：候选发布白名单、密钥/隐私/来源/依赖许可检查，以及尚未解除的发布阻塞项。
- `docs/phase6-progress.md`：本次命令、结果、产物与未完成项。
- `README.md`：增加按目的阅读的入口，不改写历史真实失败记录。
