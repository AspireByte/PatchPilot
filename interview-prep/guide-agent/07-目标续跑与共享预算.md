# C07 目标续跑与共享预算：自动继续为什么仍然可控

> 课程性质：核心
> 返回：[导学](../PatchPilot/导学.md)；前置：[C02](02-模型与工具循环.md)、[C05](05-上下文压缩.md)、[C06](06-长期记忆.md)；下一课：[C08](08-代码验证与证据.md)。
> 对应：B1；[Q2](../PatchPilot/面经.md#q2-可控-agent-循环与目标续跑)；目标掌握：理解机制、设计与表达。

## 本课重点

普通聊天模型结束就返回；显式激活目标后，工作模型结束才进入无工具评估。如果证据不足且仍可继续，就把评估反馈作为数据写入后续提示，再运行工作循环。评估器是另一次判断请求，不是另一个能自行执行工具的 Agent。

工作、评估、压缩和自动记忆提取共享本次提交的模型次数、已知 token 与总时限。把成本藏到辅助调用里会绕过预算，因此辅助请求也需要统一计数和取消。

## 主链与职责

`/goal 条件 → active → 工作循环 end_turn → 预算检查 → 无工具评估 → 严格解析 → achieved / paused / active继续`。

`GoalController` 只持有条件和状态；Session 调度模型与工具；`ExecutionControl` 传播停止信号。自动续跑次数达到限制会暂停并保留目标，恢复会话也先暂停，必须显式继续。

## 源码阅读

从 [goal.py](../../src/patchpilot/session_runtime/goal.py) 的 `set / accept / pause / resume` 看状态机，进入 [session.py](../../src/patchpilot/session_runtime/session.py) 的 `submit / _call / _check_budget / _handle_loop_event`。工作模型由 [loop.py](../../src/patchpilot/core/loop.py) 计数；摘要在循环内经 `complete_auxiliary`，其事件同步回会话统计。预算字段见 [budget.py](../../src/patchpilot/core/budget.py)。

评估结果要求字段恰好为 `ok / reason / impossible`，布尔类型严格，reason 非空，ok 与 impossible 不可同真。`ok=false, impossible=false` 保持 active；`impossible=true` 暂停；协议不合法也暂停，避免把模糊自然语言当成成功。

取消继续读 [control.py](../../src/patchpilot/core/control.py)、[Anthropic provider](../../src/patchpilot/model/providers/anthropic.py) 的 `_controlled_complete`，以及 [process/runner.py](../../src/patchpilot/infrastructure/process/runner.py) 的 `run_process`。模型请求和 watcher 竞争完成，取消后清理未完成 asyncio task；进程执行则轮询时限并回收进程树。

## 机制与边界

核心预算默认 8 次模型、32 次工具、180 秒，`AgentSession` 自己的默认覆盖为 24 次、64 次、600 秒；CLI 还可传入实际预算。上限不是实际使用量，更不能写成性能指标。默认重复指纹阈值为 3，默认自动续跑上限 8；已知 token 阈值不是精确金额硬上限，usage 缺失时另计未知调用。

本轮开始记录单调时钟，往下传剩余时限，不让每次工具或评估重新拿到完整轮次时间。输出 token 按剩余已知预算收窄，但输入、缓存与未知服务端用量仍可能导致实际花费超出直观估算。模型请求失败或取消也不代表服务端绝对没有处理或收费。

进程输出由读线程持续排空，只保留末尾有限字节，防止管道堵塞与内存增长；输出截断必须保留标志，不能用未展示的内容做验证结论。Windows 通过 Job 管理子进程，其他平台通过进程组清理；终止命令不能回滚已经写入的文件。

评估 prompt 要求区分工具 `ok` 与嵌套检查状态、区分宿主与隔离证据、核对代码版本。它减少错误达成判断，但评估仍是模型判断，不能替代独立测试。严格 JSON 保证结果可解析，不保证结论语义正确。

## 需要懂什么

自动续跑应同时具备“继续依据”和“停止依据”。继续依据是目标未满足且还有可补证据；停止依据包括预算、取消、不可验证条件、协议错误和续跑上限。只写 while true 会把模型不确定性变成无限副作用。

不同计数层必须同步：循环计工作和内部摘要，会话事件把这些反映到累计统计；外层评估与记忆也增加本轮计数。状态统计和远端账单是不同信息，未知用量应该保留，不能强行记零。

## 需要记住什么

- 无显式目标就不调用评估器；评估器 tools 为空，只判已有证据。
- 本轮预算跨工作、评估、压缩、自动记忆共享；手动管理操作有独立本次预算。
- 取消需传播到网络请求、工具与进程清理；已发生副作用不会自动撤销。
