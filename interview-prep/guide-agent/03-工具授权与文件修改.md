# C03 工具授权与文件修改：修改的是哪个版本

> 课程性质：核心
> 返回：[导学](../PatchPilot/导学.md)；前置：[C02](02-模型与工具循环.md)；下一课：[C04](04-会话持久化与恢复.md)。
> 对应：B2；[Q3](../PatchPilot/面经.md#q3-工具授权与文件版本)；目标掌握：理解机制、设计与表达。

## 本课重点

模型读到版本 A，用户随后在编辑器改成 B，再要求 Agent 写回 A 的修改时，文件工具会拒绝过期写入。它同时检查调用携带的摘要与当前进程实际读取记录。新建文件用独占创建，覆盖文件用同目录临时文件替换。

工具定义会隐藏未授权能力，执行入口仍再次检查。路径约束保护文件工具；已授权宿主命令拥有宿主进程权限，不能套用文件工具的边界来宣称沙箱隔离。

## 主链与职责

`Provider 工具定义 → ToolRegistry/ToolExecutor → LocalTools.dispatch → 权限检查 → Pydantic 参数校验 → path → 读取摘要校验 → 保存基线 → 再次比较 → 写入 → 清除读取授权`。

`observed` 保存本次进程看到的版本，`baselines` 保存首次修改之前的内容供 diff 使用。二者不是同一份状态：基线可恢复，读取授权不可恢复。

## 源码阅读

读 [builtin/factory.py](../../src/patchpilot/tools_runtime/builtin/factory.py) 和 [registry.py](../../src/patchpilot/tools_runtime/registry.py) 看内置工具如何进入注册分发。然后读 [builtin/filesystem.py](../../src/patchpilot/tools_runtime/builtin/filesystem.py) 的参数类与 `digest`，再沿 [builtin/local.py](../../src/patchpilot/tools_runtime/builtin/local.py) 的 `definitions → dispatch → path → _execute` 进入真实写入。

关键条件原样摘录：

```python
if actual != args.expected_hash or (
    old is not None and self.observed.get(args.path) != actual
):
    raise ValueError("文件版本冲突或未读取，请重新读取文件后修改")
```

只知道哈希但没有通过本次 `read_file` 读取，不能覆盖已有文件；只通过读取却带过期哈希，同样不能覆盖。读取分页时摘要针对完整文件字节，但返回文本可能截断，所以“版本已读”不表示模型已经看见全部内容。替换旧文本还要求全文唯一匹配，以避免误改多个位置。

## 机制与边界

路径入口拒绝绝对路径、`..`、反斜杠、盘符、空片段、敏感/隐藏路径、符号链接和 Windows junction，并核对解析结果仍在仓库内。文件大小有 256 KiB 上限，输出也有界。它减少越界与模型误用，但不是对恶意并发替换链接的完整操作系统级隔离证明。

已有文件写入前先保存首次基线，再检查当前字节是否仍与读取版本一致，最后 `os.replace` 替换同目录临时文件。这防止读到半份新文件，却仍存在最后一次比较到替换之间的竞态窗口：外部编辑器可以在此间写入，原子替换并不等于原子比较交换。准确的说法是乐观并发检查和原子文件替换，不是跨编辑器串行化。

成功修改后 `observed.pop` 清除授权，下一次覆盖必须重新读。恢复也创建新的工具实例，因此旧读取记录不继承。`get_diff` 比较的是本会话工具首次修改前与现在的内容，不是 Git HEAD 差异；命令直接修改的文件可能不在基线中。

`run_command` 显式启动 shell；`run_harness_check` 只能选已经加载的 profile。二者的授权、作用范围和证据级别不同，见 [C08](08-代码验证与证据.md)。

## 需要懂什么

schema 约束参数形状，权限检查决定是否允许动作，路径检查决定文件工具可访问哪里，版本校验决定能否以已观察内容为基础写回。四层解决不同问题，提示模型“谨慎操作”无法替代它们。

乐观方案不长期锁仓库，适合与编辑器共用目录；遇到冲突要求重读，代价是额外往返。若重新设计强并发编辑，应考虑协作锁、受控工作树或系统级目录句柄方案，并明确其他进程是否遵守；当前尚无这种全局保证。

## 需要记住什么

- 修改前：当前字节摘要＝调用预期摘要＝本次读取摘要。
- 修改后：保留最初 diff 基线，清除读取授权；新建用 `xb`，覆盖用临时文件替换。
- 文件工具路径限制、宿主命令权限、Docker 隔离属于不同边界。
